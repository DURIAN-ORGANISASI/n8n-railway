# Contributing

Thanks for improving this starter. Please:

1. Keep secrets, access tokens, `.env` files, and real Railway credentials out of commits and issues.
2. Explain the Railway/n8n version and reproduce any deployment problem without exposing secrets.
3. Run `python scripts/validate-repo.py` before submitting a pull request.
4. Test configuration changes on a disposable Railway project when possible.
5. Do not silently change the pinned n8n version; include a note about tested upgrade behavior.
